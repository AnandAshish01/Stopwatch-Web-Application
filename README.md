## 🚀 Project Overview

This Stopwatch Web Application was developed as part of my **second task** during my internship at **Prodigy InfoTech**. The goal was to create a fully functional, user-friendly stopwatch using **HTML**, **CSS**, and **JavaScript**.

It features essential time-tracking controls like **start**, **pause**, **reset**, **lap recording**, and **lap clearing**, all packed into a sleek, responsive interface.

---

## ✨ Key Functionalities

- ▶️ **Start** – Initiates the stopwatch.
- ⏸️ **Pause** – Halts the stopwatch while preserving the current time.
- 🔁 **Reset** – Resets the time display to 00:00:00.
- 🏁 **Lap** – Records current elapsed time as a lap.
- 🗑️ **Clear Laps** – Clears all recorded laps.
